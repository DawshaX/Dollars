# Story and world-memory layer — authored pilot planning

Added content/world.json: a fictional dew-drop city, a working caretaker character design, visual/audio rules and three continuity flags. Character name is provisional and not cleared for exclusive use.

Added studio/story.py: two authored six-beat story outlines, duration/camera/action/sound planning, story fingerprint uniqueness across formats, prerequisite checks and transactional continuity updates on an explicit publication-confirmation call. Confirmation requires the expected channel ID and video-ID syntax; it does NOT itself query YouTube. A future caller must perform real verification; passing a string is not evidence of publication.

Pilot outline: lost_sun, a 24-second short with six four-second shots. It is a shot plan, NOT rendered footage, a finished storyboard, a character model or a validated film. Content/world.json and story data are authored, not generated by an AI service.

The second story is blocked until the first publication is confirmed. Planning does not change world state. Repackaging the same story as a different format is not treated as new content. Long-form is deliberately refused until a genuinely expanded narrative recipe exists, rather than padding the short.

Run from nova_studio/:

    python -m studio.story --db world.sqlite --out story_plans
    python -m unittest discover -s tests -v
