# 🏗️ معمار استوديو Dollars (المخطط الفني التنفيذي)

## المبدأ الحاكم
> **كل فيديو = قطعة أصلية مملوكة بالكامل (IP بتاعنا)، مفهومة من أي حد في العالم بدون ترجمة، ومتنوّعة عن اللي قبلها.**

## خطوط الإنتاج الخمسة

### 1) 🎨 خط المشاهد (engine/)
| الوحدة | الوظيفة | الحالة |
|---|---|---|
| `scenes_cosmos.py` | مجرات/كواكب/نجوم مولّدة + حركة بطيئة | مخطط |
| `scenes_nature.py` | مطر/غابات/بحر/ثلج (مولّد بالكود + خامات CC0 مسجّلة) | مخطط |
| `scenes_surreal.py` | عوالم حلم/سريالي (مشاهد مش واقعية = مفيش مشكلة إفصاح) | مخطط |
| `render.py` | مونتاج ffmpeg + انتقالات + صوت + كابشن | مخطط |
| `license_gate.py` | **بوابة إجبارية**: أي خامة مش في سجل الترخيص = رفض | مخطط |

### 2) 🧸 خط الشخصيات (characters/)
- كل شخصية: `shape` (شكل/رسم) · `motion` (حركة) · `voice` (صوت) · `personality` (سلوك).
- الملكية 100% — مولّدة بالكود/AI، مفيش أي شخصية مشهورة ولا شبيهة.
- أول 3 شخصيات: كائن طيني فضولي · قطة سحابية هادئة · رجل ورقي في عوالم غريبة.

### 3) 🔊 خط الصوت (voice/)
- أصوات نيورالية مملوكة + طبقات أداء (هدوء · دهشة · ضحك · همسة).
- **الهمس والسرد = مفتاح الدبلجة التلقائية** (يوتيوب بيدبلج الفيديو اللي فيه كلام لـ27 لغة).
- ممنوع: أي صوت لشخص حقيقي.

### 4) 📦 خط التغليف (content/ + i18n/)
- عناوين: نية بحث حقيقية بلغة السوق + إحساس.
- أغلفة: **بلا كلام** (صورة تتفهم عالميًا) — 3 عناصر بالكتير.
- وصف: أول سطرين يوقفوا، بعدهم سياق + مصادر + دعوة تفاعل.
- التعليق يتترجم لـ6 لغات أساس (EN/ES/PT-BR/HI/ID/AR) ثم 27 بالدبلجة.

### 5) 📡 خط النشر والمراقبة (workflows/)
- `dollars-shorts.yml` كل ساعة · `dollars-long.yml` كل 4/6/8/12 ساعة.
- تناوب مشاريع جوجل لحصة الرفع (كل مشروع 6/يوم).
- خزّان + نبضة + حارس + مفتّش (المصنع ما يوقفش أبدًا).
- رادار ترند كل 6 ساعات → تقرير «فورمات بتكسب» → نبنيها بمحتوى بتاعنا.

## البوابات الإجبارية قبل أي رفع (كلها في الكود — مش كلام)
| البوابة | القاعدة | العقوبة لو اتخطّت |
|---|---|---|
| 🎵 الترخيص | كل ميديا (صوت/صورة/فيديو) مسجّلة بمصدرها | رفض الرفع |
| 🔎 الانتحال | أي صوت/شكل لشخص حقيقي → رفض | رفض الرفع |
| 🤖 الإفصاح | تسجيل «وسائط مولّدة» مع أي محتوى واقعي مُصنّع | رفض الرفع |
| 🎲 التنويع | ممنوع تكرار (شخصية+عالم+بنية) قبل استهلاك الاحتمالات | إعادة توليد |
| 💎 القيمة | فكرة أصلية + إيقاع + نهاية | إعادة توليد |
| ⏱️ المدة | شورتس ≤ 60ث · الطويل بلا صمت طويل | إعادة معالجة |

## 🆕 تحديث المعمار (2026-09-25): من 2D لـ3D + جودة سينمائية

```
content/ → مكتبة (مشاهد · مؤثرات · ملصقات · شخصيات) → engine/
                                                        ├─ proc.py      (ضجيج/هندسة مشتركة)
                                                        ├─ visuals.py   (12 مشهد 2D + ترميز + فيديو طويل)
                                                        ├─ render3d.py  (4 مشاهد 3D + خريطة عمق)
                                                        ├─ grade.py     (طقم الجودة السينمائية)
                                                        ├─ ambient.py   (أصوات الأجواء)
                                                        ├─ sfx.py       (32 مؤثر صوتي)
                                                        ├─ meta.py      (يوتيوب من أ ل ي)
                                                        └─ agent.py     (العقل الذاتي)
                     ↓
        state/ (العقل · الأفكار · الخطة · التعلّم) → النشر (بلا حد) → الأرقام ترجع للعقل
```

### قرارات تقنية ملزمة (لا نرجع فيها)
1. أي مشهد لازم يكون **حلقة رياضية مثالية** (الاختبار بيرفض غير كده).
2. أي عنصر بصري لازم يكون **حركة حقيقية** (اختبار الحركة بيرفض أقل من 0.002).
3. الجودة تتقاس **بالأرقام** (`grade.quality_report`) قبل النشر.
4. كل أصل لازم يبقى **ملكنا** (متولّد بالكود) — أي أصل خارجي = CC0 مع تسجيل المصدر.
5. الفيديو الطويل = حلقة واحدة + تكرار بـ`copy` (مفيش فيديو طويل في الرام).
