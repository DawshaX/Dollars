# 🔑 المفاتيح والربط — دليل سريع
> القيم **مش مكتوبة هنا** لأمان. أنا شفت أسماء المفاتيح الموجودة عندك في جيت هوب (22 في `DawshaX/youtube`
> و30 في `DawshaX/XTreNDAW`) وحددت المفيد لمصنع Dollars.

## 1) المفاتيح المطلوبة لمصنع Dollars (5 دقايق نسخ)
افتح: `DawshaX/Dollars` → **Settings → Secrets and variables → Actions → New repository secret**
وأضف **نفس القيم** الموجودة عندك بالفعل في `DawshaX/youtube` (مش هيتم كشفها، بتتنسخ من عندك):

| السرّ | ليه محتاجينه | المصدر عندك |
|---|---|---|
| `YOUTUBE_CLIENT_ID` | رفع الفيديو على قناة دوشة | موجود في `DawshaX/youtube` — نسخ القيمة |
| `YOUTUBE_CLIENT_SECRET` | نفس السبب | نفس المصدر |
| `YOUTUBE_REFRESH_TOKEN` | نفس السبب | نفس المصدر |
| `TELEGRAM_BOT_TOKEN` | إشعار بعد كل نشر | موجود |
| `TELEGRAM_CHAT_ID` | نفس السبب | موجود |

**مهم:** لو التوكن الحالي بتاع قناة تانية (مش دوشة)، سيب القناة في الآخر زي ما اتفقنا —
المصنع هيشتغل ويحفظ كل حاجة في **الطابور** بنفس الوصفة، ولما نركّب توكن دوشة نجري:
`python engine/factory.py --render-queue` → يعيد إنتاج كل حاجة **بنفس البذرة بالظبط** وينشرها.

## 2) المفاتيح الإضافية المفيدة (مسجّلة عندك بالفعل — نقدر ننقلها وقت اللزوم)
| السرّ | الفايدة لمصنعنا |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID`* + `CLOUDFLARE_API_TOKEN`* | صور شخصيات FLUX (170-230 صورة/يوم مجانًا) — `engine/assets_ai.py` جاهز |
| `GROQ_API_KEY` | مساعد ذكي: تلخيص أفكار · تحسين عناوين · ترجمة الوصف بسرعة وبلا فلوس |
| `GEMINI_API_KEY` | نفس الفايدة + مراجعة الأوصاف |
| `PEXELS` / `PIXABAY_API_KEY` | خلفيات مجانية للتراخيص المسموحة (مع تسجيل المصدر إلزامي) |
| `NASA` / `NASA_API_KEY` | صور فضاء حقيقية (ملكية عامة) لسيناريوهات الفضاء |
| `OPENVERSE` | صور CC0 (بس مكتبتنا المولّدة أولى دائمًا) |
| `YOUTUBE_API_KEY` | قراءة إحصائيات الفيديوهات → يغذّي **العقل الذاتي** بالأرقام |
| `TELEGRAM_*` | إشعارات |

(*) `CLOUDFLARE_*` هو الوحيد اللي مش موجود — يتضاف لو عايز صور شخصيات بجودة عالية ومجانًا.

## 3) تفعيل العقل على الأرقام الحقيقية (خطوة واحدة)
1. أضف `YOUTUBE_API_KEY` في Dollars.
2. سير العمل اليومي بيشغّل `engine/agent.py` تلقائيًا — كفاية نملأ `state/analytics.json` من الـAPI
   (السكربت `engine/agent.py --sync`* بيجمعه تلقائيًا أول ما المفتاح يبقى موجود).
   *\* الهوك موجود في `agent.learn()` — بنوصّله بالـAPI في أول يوم نشر.*

## 4) إعدادات الاستوديو — كل النصوص في ملف واحد
`docs/BRANDING.md`: الاسم · الوصف (إنجليزي + عربي) · الهاندل البديل · البلد · الكلمات المفتاحية ·
البلايليستات · أسلوب الأغلفة · الجدول المعلن — كل حاجة جاهزة للنسخ.

## 5) أوامر اليوم الأول بعد الربط
```bash
python engine/factory.py --status          # اتأكد إن التوكن شغال
python engine/factory.py --hourly --count 1   # شورت تجربة
python engine/factory.py --daily --count 1    # طويلة تجربة
python engine/factory.py --render-queue       # انشر كل اللي في الطابور (بنفس الوصفات)
```
