# 🔎 المرجع البصري + بحث السوق (كله حقيقي · كله شغّال)
> المصنع **بيبحث بنفسه**: يشوف الشكل اللي ناجح بره (مرجع بصري) وأرقام المشاهدات الحقيقية (سوق) — ويستخدمهم
> في تحسين الخط والمشاهد والعناوين… من غير ما ياخد **ملف واحد** من حد.

## 1) Pinterest — مرجع بصري (بالعين، بلا سرقة)
```bash
python engine/refs.py --pinterest "rain on window night"
```
بيطلّع **روابط بحث Pinterest جاهزة** (مزاج · لوحة ألوان · تكوين · إضاءة) — تشوف وانت بتحدّد شكل المشهد.
**مش** بنسحب صور Pinterest ولا بنستخدمها في فيديو (شروط Pinterest + قاعدة صفر سرقة).

## 2) لوحة مراجع مصوّرة (بترخيص موثّق)
```bash
python engine/refs.py --board "cozy fireplace ambience" --limit 8
```
بتسحب **صور مرجعية صغيرة** من **Openverse** (بلا مفتاح) — ولو مفاتيحك موجودة: **Pixabay** و **Pexels**.
كل صورة بتتسجّل بمصدرها وترخيصها في `docs/refs/<الموضوع>/` + `state/refs.json`.
> ⚠️ **مرجع بصري فقط** — ممنوع تدخل في أي فيديو. (لو حبينا نستخدم أصل حقيقي: لازم CC0 ونسجّل مصدره.)

## 3) أرقام السوق الحقيقية (يوتيوب)
```bash
python engine/refs.py --trends --apply
```
بيسحب **أعلى الفيديوهات مشاهدة** في تخصصاتنا (ترتيب المشاهدات من صفحة نتائج يوتيوب نفسها) →
`state/trends.json` + **يغذّي العقل** بلطف (يعدّل أوزان الأنواع على حساب الطلب الحقيقي).

**نتيجة آخر تشغيل (حقيقية):**
| المجال | أعلى مشاهدات | الفيديو |
|---|---|---|
| rain/black screen | 378,428,580 | White Noise Black Screen (Sleep, Study, Focus) |
| wordless animation | 556,150,679 | Pip — A Short Animated Film |
| satisfying | 209,471,753 | Kinetic Sand (افتراضي) |
| fireplace ambience | 165,237,491 | Fireplace Ambience |
| **الطلب المستخرج** | sleep 31 · focus 15 · satisfying 8 · story 8 | ← العقل استخدمه فورًا |

## 4) اللي بياخده العقل من ده
- **الأنواع**: يزود وزن النوع اللي السوق عايزه (بدون ما يلغي التوزيع).
- **العناوين**: كلمات البحث الغالبة تدخل قاعدة العناوين (mtitle/kw pool).
- **الشكل**: الشرائط المرجعية توجّه `LOOKS` والألوان والتكوين في المشاهد.


## من المرجع البصري لإعدادات الفيديو (مش ديكور — شغل حقيقي)

`refs.look_recipe("rain on window night")` بترجّع وصفة مونتاج: **مظهر** (look) · **حركة كاميرا** (moves) ·
**مشاهد** (scenes) · **موسيقى** (music) · **ألوان** (palette) · **مزاج** (mood) — والمصنع بيمرّرها للمخرج:

    rec = refs.recipe_for("satisfying")        # أو أي تخصص/كلمة
    ed.make("satisfying_short", seconds=30, look=rec["look"], moves=rec["moves"],
            scenes=rec["scenes"], music=rec["music"])

- **Pinterest** بيحدّد المزاج/الألوان/التكوين — والمشاهد والأصوات **من عندنا** (مفيش ملف خارجي).
- `state/refs.json` فيه كل وصفة استُخدمت + اللوحات + روابطها.
- الطويلة: الحركة تيجي من الوصفة، والمظهر من المشهد نفسه (المشهد أعرف بمظهره).
- CLI: `python engine/refs.py --recipe "cozy fireplace"`.
