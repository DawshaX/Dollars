# ⚖️ دستور الحقوق (صفر خطر — إلزامي في الكود)

## مسموح
1. **مولّد عندنا بالكود** (مشاهد، أجواء، موسيقى إجرائية) — ملكنا 100%.
2. **خامات بملكية عامة** موثّقة (NASA / Public Domain) مع رقم المصدر.
3. **CC0 / CC-BY بمصدر مكتوب** (CC-BY يتكتب في الوصف).
4. **شخصيات وأصوات بتاعتنا** — مملوكة، ومن غير أي شبه بأشخاص حقيقيين.

## ممنوع (رفض تلقائي في بوابة الترخيص)
1. أي مقطع/صوت متحمّل من يوتيوب/تيك توك/أي منصة.
2. تقليد صوت شخص حقيقي (مشهور أو عادي) — انتحال شخصية.
3. موسيقى أو أغنية محمية.
4. شعارات/علامات تجارية داخل الفيديو.
5. مشاهد لشخصيات محمية (ديزني/أنيمي وغيرها).

- المحتوى الكرتوني/الواضح إنه رسم = مش محتاج العلامة، بس نسجّلها في السجل للمراجعة.
